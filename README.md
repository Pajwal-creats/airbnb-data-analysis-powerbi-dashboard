# Airbnb Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project analyzes Airbnb listing data using Python and Power BI to understand pricing, availability, room types, neighbourhoods, reviews, and host activity.

The project follows a simple data analytics workflow:

**Raw Data → Python Data Cleaning → Power BI Dashboard → Insights**

## 🛠️ Tools Used

* Python
* Pandas
* Power BI
* Git & GitHub

## 📊 Dashboard Pages

### 1. Airbnb Overview

* Total Listings
* Average Price
* Listings by Room Type
* Average Price by Room Type
* Top Neighbourhoods by Listings

### 2. Price & Availability

* Top Neighbourhoods by Average Price
* Average Availability by Room Type
* Price vs Minimum Nights

### 3. Reviews & Host Insights

* Top Hosts by Listings
* Reviews by Room Type
* Average Monthly Reviews by Room Type

## 🐍 Python Data Preparation

Python was used to prepare the Airbnb dataset for analysis, including data loading, cleaning, and preparation for Power BI.

The main Python script is:

`airbnb_analysis.py`
